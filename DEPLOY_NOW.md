## 🐛 If Deployment Fails

### Common Issues & Solutions:

**Issue:** "Module not found"
- **Fix:** Check requirements.txt has all dependencies
- Usually fixes itself on retry

**Issue:** "App won't start"
- **Fix:** Check app.py exists in root directory
- Verify no syntax errors in main files

**Issue:** "Database error"
- **Fix:** App will auto-create database on first run
- This is normal and expected

**Issue:** Build timeout
- **Fix:** Retry deployment
- Streamlit Cloud sometimes has queue delays

**Most issues fix with:** Click "Reboot app" in Streamlit dashboard
